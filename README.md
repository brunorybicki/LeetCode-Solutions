# LeetCode Solutions
This repository contains my solutions to programming problems from [LeetCode](https://leetcode.com/).
\
The solutions were created as part of my practice in algorithms, problem solving, data structures, and technical interview preparation.

## Repository Structure
Each problem is stored in its own directory named using the corresponding LeetCode problem number and title.
\
Source files use a simplified version of the problem title as their filename.
\
Some problem directories may contain solutions written in more than one programming language.

## Languages

The repository currently contains solutions written in C.
\
Additional languages may be added in the future.

## Purpose
This repository serves as a record of my progress in:
- Algorithmic problem solving
- Data structures and algorithms
- Technical interview preparation
- Writing efficient and concise programs
- Practicing different programming concepts and languages

## Notes
- Each directory corresponds to a problem from LeetCode.
- Problem statements are not reproduced in this repository.
- Source files contain my own implementations of the solutions.
- Some problems may contain multiple implementations in different programming languages.
- Solutions may not always represent the most optimal possible approach, as this repository also documents my learning progress.
